Privacy Policy

Information We Collect

When you use our captive portal service, we collect:

  • Device MAC address
  • IP address
  • Browser user agent
  • Session information
  • Connection timestamps

How We Use Your Information

We use the collected information for:

  • Network access management
  • Usage monitoring
  • Security purposes
  • Technical troubleshooting

Data Retention

Connection logs are retained for a limited period for security and troubleshooting purposes. User account information is maintained until account deletion is requested.

Security

We implement appropriate security measures to protect your information. However, please note that no method of transmission over the internet is 100% secure.
